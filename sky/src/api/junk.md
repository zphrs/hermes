Ultimately we assume that the IP address of users in the network is public information by virtue of needing such an IP address when it comes to enabling communications with other nodes in the network. We also assume that when a specific IP address is online is also public information, provided that IP address has opted into the mode where all nodes, even nodes outside of their whitelist can talk to them. In the case where an earth node has enabled the mode to limit incoming egress from outside of its whitelist, we assume that having sky nodes rotate regularly throughout the day somewhat challenges the ability to accurately track when a given earth node is online. That said, since sky nodes can potentially engage in DOS behavior, an earth node might want to use multiple sky nodes to connect into the network.

The earth nodes talk to the sky nodes in order to find out about other earth nodes. This communication will require an earth node registering with a specific sky node. Once an earth node has been registered with a sky node, other earth nodes can query for the earth nodes connected to a given sky node and request to be connected with that earth node. The request process involves getting consent from both the earth node and the sky node before going through with the connection. This handshake process involves the initiating earth node to send a package including its public keys.
